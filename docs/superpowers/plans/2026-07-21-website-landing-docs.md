# Vector Website (Landing + Docs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hosted landing page + documentation site for Vector on GitHub Pages, built with Astro + Starlight, plus a slimmed README that links to it. Ships with placeholder images (real screenshots swapped in later).

**Architecture:** A self-contained Astro project in `website/` — a custom `src/pages/index.astro` landing page owns `/`, and Starlight serves markdown docs from `src/content/docs/`. Deployed to GitHub Pages (source: GitHub Actions) at `https://avram19.github.io/vector/` (Astro `base: '/vector'`).

**Tech Stack:** Astro, `@astrojs/starlight`, Node 20, GitHub Actions (`withastro/action` + `actions/deploy-pages`).

## Global Constraints

- **No test framework.** Verify every task with `npm --prefix website run build` (must succeed) and, for visual tasks, `npm --prefix website run preview` + observing the page in a browser. A task is not done until its build is green and (for UI) the page renders as described.
- **Pinned deps** in `website/package.json` — exact versions, no `^`/`~` (match repo policy). Install with `--save-exact`; commit the resolved versions.
- **Base path is `/vector`** — every internal link and asset must resolve under it. Use Astro's `import.meta.env.BASE_URL` / relative content links; never hardcode a leading-`/` absolute path that ignores the base.
- **Keep the "How it was built" vibe-coded disclosure** — it appears verbatim on the landing and stays in the README. Its exact text is in the current `README.md` under `## How it was built` (lines ~152-158). Do not reword it.
- **Placeholders now** — images are labeled, correctly-sized SVG placeholders committed at the real target paths; swapping a real PNG in later is a one-file change.
- **Adapt, don't reinvent** — docs content is adapted from the existing `README.md`, `CLAUDE.md`, and `docs/superpowers/specs/`. Cite the source; don't write net-new where it already exists.
- **License:** PolyForm Noncommercial 1.0.0 (footer + README).
- **Repo:** `avram19/vector`. Agent list (verbatim, for the landing + docs): Claude Code, Codex, Cursor Agent, GitHub Copilot CLI, Aider, Gemini, Amazon Q, OpenCode, Crush, Goose, Amp, Plandex, Continue, Qodo, + raw shell.

## Task 2: GitHub Pages deploy workflow

**Files:**
- Create: `.github/workflows/pages.yml`

- [ ] **Step 1: Write the workflow**

```yaml
name: pages
# Build the website/ Astro site and deploy to GitHub Pages.
# One-time manual step: repo Settings > Pages > Source = "GitHub Actions".
on:
  push:
    branches: [main]
    paths: ["website/**", ".github/workflows/pages.yml"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

# Allow one concurrent deploy; don't cancel an in-progress one.
concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: withastro/action@v3
        with:
          path: ./website
          node-version: 20
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

Note: `withastro/action` runs the build and uploads the Pages artifact; `deploy-pages` publishes it.

## macOS
Download the latest `.dmg` from [Releases](https://github.com/avram19/vector/releases), drag Vector into `/Applications`, open it. Because the build is unsigned, Gatekeeper blocks it the first time — right-click → Open → Open, or `xattr -dr com.apple.quarantine /Applications/Vector.app`.

## Linux
Vector runs on x86_64 and aarch64 via WebKitGTK.
- **.deb (recommended):** `sudo apt install ./Vector_<ver>_amd64.deb` (apt pulls the WebKitGTK deps); launch **Vector** from your app menu.
- **AppImage:** `chmod +x Vector_<ver>_amd64.AppImage && ./Vector_<ver>_amd64.AppImage`. If a lib is missing: `sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0 libayatana-appindicator3-1`.

Clipboard file-paste uses `wl-clipboard` (Wayland) or `xclip` (X11).
