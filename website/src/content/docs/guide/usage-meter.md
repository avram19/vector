---
title: Claude usage meter
description: Live usage bars in the topbar for the active Claude pane.
---

When a Claude pane is focused, the topbar shows live usage bars for your **5-hour** and **7-day** windows, so you can see how close you are to a rate limit without leaving the terminal.

The meter reads usage for the [Claude profile](/vector/guide/profiles/) active in that pane, so switching profiles or tabs shows the right account's usage.
