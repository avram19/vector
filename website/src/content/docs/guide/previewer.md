---
title: File previewer
description: Inline preview of code, diffs, markdown, mermaid diagrams, PDFs, and images.
---

⌘-click any file path printed by an agent to open a read-only preview in a side pane on the same tab. ⌘⇧-click pins a second preview for side-by-side compare.

## What it renders

- **Code** — syntax-highlighted for common languages (JS/TS, Python, Rust, Ruby, and other common formats).
- **Markdown** — rendered with embedded Mermaid diagrams.
- **Mermaid** — standalone `.mmd`/Mermaid diagrams render directly.
- **Diff** — unified diffs (e.g. from the Worktrees tab) with syntax highlighting.
- **PDF** — inline PDF viewer.
- **Image** — inline image preview.

## Actions

Right-click any path or preview pane for **Reveal in Finder**, **Open in default app**, or **Copy path**. From the [sidebar's Files tab](/vector/guide/sidebar/), you can also **Open in installed editor** (VS Code / Cursor / Zed / Windsurf / WebStorm / IntelliJ / PyCharm / Sublime).
