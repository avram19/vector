---
title: First run
description: What to expect the first time you open Vector.
---

On first launch, Vector will ask for Notification permission (so agents can alert you when they need input) — grant it in System Settings if you dismiss the prompt.

Vector runs agent CLIs inside each tab, so install at least one (e.g. `claude`) before you start, or pick **shell** in the agent dropdown to get a plain terminal.

Vector scans your `PATH` and only shows agents it actually finds installed. The project picker opens on `⌘T` — pick a folder, then pick an agent (or shell) for the new tab.
